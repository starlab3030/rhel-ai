## 1 Podman AI Lab 레시피 실행

### 1.1 AI 애플리케이션 실행의 복잡성

**최신 AI 앱 구성**
* 일반적인 프런트엔드, 백엔드 또는 데이터베이스 구성에  애플리케이션에 AI 기능을 주입하는 모델이 필요
* 사용하는 모델에 따라 실행하고 애플리케이션에 통합 필요

**앱과 모델 통합**
* 간단하고 고전적인 머신 러닝 모델
  + 쉽게 통합
  + 라이브러리를 애플리케이션에 임포트하여 선택한 모델을 실행
  + 예) ***Scikit-learn*** 라이브러리에 포함된 모델이 여기에 해당
* 복잡한 모델의 경우
  + 모델을 독립적인(전용) 서비스로 실행
  + 전용 리소스를 할당
  + 최적화된 방식으로 확장 가능
* 대규모 언어 모델(LLM)의 경우
  + 일반적으로 모델에 상당한 컴퓨팅 및 메모리 리소스를 제공
  + 모델 서비스가 애플리케이션의 나머지 부분과 통신하는 방식도 정의
    - 통신은 일반적으로 API를 통해 처리
  + 모델에 전달하기 전에 입력 데이터의 전처리가 필요
<br>

### 1.2 Podman AI Lab에서 레시피란

#### 1.2.1 Podman AI Lab의 레시피 기능

* 사용자 워크스테이션에서 AI 애플리케이션의 모든 구성 요소를 빠르게 빌드하고 실행할 수 있는 간편한 방법
* 레시피는 일반적인 사용 사례에 대한 예제 AI 애플리케이션과 소스 코드를 제공
  + 새로운 애플리케이션의 청사진으로 사용
* 레시피는 애플리케이션 구성 요소를 컨테이너처럼 관리
  + 예를 들어, 레시피는 백엔드, 프런트엔드, 데이터베이스를 동일한 애플리케이션의 컨테이너로 배포 가능

#### 1.2.2 AI 모델의 레시피

**Podman AI Lab에서 모델 서비스**
* 모델을 실행하고 API를 통해 노출하는 컨테이너화된 모델 서비스로, 백엔드를 제공
* 각 모델 서비스는 특정 모델 계열을 지원
* 예) LLM의 경우
  + Podman AI Lab은 llama_cpp 백엔드 기반의 모델 서비스를 제공
  + 해당 모델 서비스는 LLM의 양자화된 버전을 실행
    - GPU와 같은 특수한 컴퓨팅 가속기 없이도 로컬 워크스테이션에서 이러한 LLM을 실행 가능

#### 1.2.3 레시피 종류 및 개념

**Podman AI Lab 레시피 종류**
* 기본적으로 다운로드하여 실행할 수 있는 여러 레시피를 포함
* 대부분의 레시피는 자연어 처리 사용 사례에 중점
* 이미지 및 오디오 처리를 위한 다른 레시피도 제공
* 사용자가 직접 레시피를 만들 수 있음

**Podman AI Lab 레시피의 두가지 개념**
|$\color{lime}{\texttt{분류}}$|$\color{lime}{\texttt{소분류}}$|
|:---|:---|
|**레시피**|레시피는 컨테이너화된 AI 애플리케이션을 빌드하고 실행하는 방법을 정의하는 매니페스트|
|**AI 앱**|레시피를 실행하여 생성된 애플리케이션의 실행 중인 인스턴스<br>하나의 레시피를 사용하여 동일한 애플리케이션의 여러 인스턴스를 빌드하고 생성|
